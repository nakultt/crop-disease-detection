PlantGuard demo images
======================

Leaf photos from the PlantVillage dataset (training split). Each file is
named after the result the app shows for it, and was checked against the
deployed model (pc/public/models/model.onnx).

Upload any of them in the web app (Scan Crop) or the Android app (Gallery).
